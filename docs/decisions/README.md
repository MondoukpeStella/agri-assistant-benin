# Décisions d'architecture

Ce dossier conserve les décisions structurantes du projet. Une décision provisoire reste marquée comme telle. Une hypothèse non validée n'est pas enregistrée comme une décision acceptée.

Format : `ADR-NNN-titre-court.md`.

Le modèle vide est [`ADR-000-template.md`](ADR-000-template.md).
